## 🔍 审核要点

### 1. 单词准确性
- [ ] 日语单词是否正确
- [ ] 是否包含错误的字符（如中文释义混入单词字段）
- [ ] 片假名单词是否正确识别

### 2. 读音准确性
- [ ] 假名读音是否正确
- [ ] 音调是否正确标注
- [ ] 是否有读音错误或遗漏

### 3. 释义准确性
- [ ] 中文释义是否完整准确
- [ ] 是否包含词性标记（名·动·形等）
- [ ] 多义词是否列出主要含义

### 4. 记忆方法质量
- [ ] 记忆元素是否清晰易懂
- [ ] 场景记忆是否具体生动
- [ ] 复习提示是否简洁有效

### 5. 例句质量
- [ ] 日语例句是否自然
- [ ] 中文翻译是否准确
- [ ] 例句是否有助于词汇记忆

## 🛠️ 常见问题修复

### 问题1: 单词字段混入释义
**示例**: `word: "大量，多量，大批；大度量"`
**修复**: 将单词改为正确值 `大量`，释义保留完整内容

### 问题2: 读音解析错误
**示例**: `reading: "名"`
**修复**: 根据PDF原始内容修正读音

### 问题3: 词性标注缺失
**修复**: 添加 `partOfSpeech` 字段
