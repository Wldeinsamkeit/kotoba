## 📋 核心工作流程

```
┌─────────────────────────────────────────────────────────────┐
│                    开始处理新批次单词                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  1. 读取规则文件                                             │
│     data/skill/日语所有单词记忆方法规则.md                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  2. 读取当前批次文件                                         │
│     data/memory_methods/nx/batch_XX_methods.json             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 按规则重写全部单词                                       │
│     - 谐音优先                                               │
│     - 故事生活化                                             │
│     - 固定读音补强  │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  4. 逐词质量校验（三道关卡）                                 │
│     ✓ 谐音现实性                                            │
│     ✓ 故事一致性                                            │
│     ✓ 情绪调动                                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  5. 展示给用户审核                                           │
│     格式：序号. 词语（意思，读音）：记忆法 - 单词意思        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  6. 用户给出批改意见                                         │
│     1、格式：e1、修改内容...  d2、删除... 
      2、根据用户提供的编号，不满意的返工修改。
      3、返工修改时能谐音的换谐音方法，谐音不够通顺的换其他记忆法。
      如同发音不同字的一起记忆，或者根据相近平假名字型的对比记忆
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  7. 按批改逐一修改文件 再将不合格单词发给用户确认，直至用户满意后停止修改                                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  8. 学习新规律，更新规则文件                                 │
│     - 新谐音/固定读音 → 添加到示例区                        │
│     - 新规则 → 添加到对应章节                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    完成，准备下一组                          │
└─────────────────────────────────────────────────────────────┘
```

## ✅ 质量校验清单

每个单词必须通过以下三道关卡：

```
┌─────────────────────────────────────────────────────────────┐
│                    关卡 1：谐音现实性                        │
├─────────────────────────────────────────────────────────────┤
│  ✓ 谐音基本符合原词发音                                    │
│  ✓ 能在真实生活里说出来                                    │
│  ✓ 不为了故事牺牲发音准确性                                │
│                                                             │
│  ❌ 不过关 → 换谐音或改拆分                                │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    关卡 2：故事一致性                        │
├─────────────────────────────────────────────────────────────┤
│  ✓ 故事由谐音延伸                                          │
│  ✓ 逻辑符合日常实际                                        │
│  ✓ 有具体人物、场景、动作、物品或情绪                      │
│                                                             │
│  ❌ 不过关 → 重写故事，不硬圆                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    关卡 3：情绪调动                          │
├─────────────────────────────────────────────────────────────┤
│  ✓ 读者能感到：搞笑/惊讶/尴尬/生气/无奈/温暖              │
│  ✓ 故事有完整小戏（不能只有谐音一句）                      │
│                                                             │
│  ❌ 不过关 → 加强具体人物/动作/后果                        │
└─────────────────────────────────────────────────────────────┘
```

## 🔧 常见问题处理

```
┌─────────────────────────────────────────────────────────────┐
│  问题：谐音太生硬/不自然                                    │
├─────────────────────────────────────────────────────────────┤
│  解决方案：                                                  │
│  1. 多试几个整体谐音，选最贴近的                            │
│  2. 拆成2-3段分别谐音，再合成故事                          │
│  3. 仍不自然 → 改用固定读音/字形联想/外来语                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  问题：故事不符合生活逻辑                                    │
├─────────────────────────────────────────────────────────────┤
│  解决方案：                                                  │
│  1. 检查是否胡编乱造                                        │
│  2. 故事要贴近日常：家庭、学校、工作、食物、钱             │
│  3. 用户给的故事通常更生活化，优先保留原味                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  问题：不知道用什么方法                                      │
├─────────────────────────────────────────────────────────────┤
│  优先级顺序：                                                │
│  1. 用户提供的谐音/故事（最高优先级）                       │
│  2. 自然中文谐音 + 生活化故事                              │
│  3. 罗马音/英语/外来语相似                                  │
│  4. 汉字直觉 + 固定读音（补强）                            │
│  5. 拆分谐音/字形联想/关联记忆                             │
└─────────────────────────────────────────────────────────────┘
```

## ⚠️ 常见错误警示

```
┌─────────────────────────────────────────────────────────────┐
│  ❌ 错误：谐音发音偏差太大                                  │
│  例：すみ→扫地（发音不符）                                  │
│  ✓ 正确：すみ→私密（发音贴合）                             │
├─────────────────────────────────────────────────────────────┤
│  ❌ 错误：故事不符合生活逻辑                                │
│  例：木卡子开门（不自然）                                   │
│  ✓ 正确：木匣子藏老照片（贴近日常）                        │
├─────────────────────────────────────────────────────────────┤
│  ❌ 错误：只有谐音没有故事                                  │
│  例：谐音"XX"就结束了                                       │
│  ✓ 正确：谐音+1-3句具体小戏（有人物/动作/后果）            │
├─────────────────────────────────────────────────────────────┤
│  ❌ 错误：硬凑谐音                                          │
│  例：每个词都要谐音                                         │
│  ✓ 正确：汉字透明/外来语明显/固定读音稳定的词不必硬凑      │
└─────────────────────────────────────────────────────────────┘
```
