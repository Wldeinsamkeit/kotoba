# 日语所有单词记忆方法规则

用途：给 `data/memory_methods/batch_*_methods.json` 批量编写或修改日语单词记忆方法时使用。这是本 app / 平台的核心记忆方法文件，不只服务 N5，也服务后续所有级别、所有批次的单词记忆生成。

核心原则：这个文件要像滚雪球一样持续变大。每一组用户修改并确认过的单词，都必须被认真复盘，提炼出可复用的记忆规律，再更新回本文件。以后生成新批次时，优先读取并遵守本文件。

## 滚雪球更新机制

每一组单词被用户修改后，必须做这几步：

1. 回看本组被修改的词条，识别用户真正想保留的规律，而不是只机械替换某一句话。
2. 检索已确认批次和本规则，判断这是旧规律复用，还是新规律升级。
3. 把新规律沉淀进本文件，优先写成可执行规则、典型示例、固定读音或易混对比。
4. 再更新对应 `batch_*_methods.json` 和草稿文件，保持规则与数据同步。
5. 给下一组词时，先用本规则生成，不要回到通用、平庸、生硬的记忆法。

需要重点沉淀的内容：

- 用户亲自给出的谐音、拆分、故事和吐槽式表达。
- 单词之间的相似点、差异点、少一点/多一点、长音/促音变化。
- 常见汉字固定读音、浊化、特殊读法。
- 能跨批次复用的故事模板，比如生活场景、学习场景、家庭对话、食物、打工、考试、出门、迷路。
- 用户纠正过的错误方向，避免后续重复生成。

质量反思要求：

- 新批次如果生成质量不高，必须回看用户批改，找出低质量原因：是否硬凑谐音、是否没有用固定读音、是否没有把相似词放一起、是否故事不贴近日常。
- 谐音必须先校准发音，不能只看中文意思就硬凑。比如 `へん` 不能谐音成发音明显偏差的“边”，应优先找更贴近发音的“恨/很/哼”等；如果候选谐音不自然，就拆假名或换字形、联想、固定读音法。
- 有固定读音、透明汉字、外来语来源时，先用稳定知识打底，再加谐音故事；不要为了搞笑牺牲准确性。
- 外来语必须核对来源和意思，不能混淆相近英语。比如 `デパート` 来自 `department store`，是百货商店；公寓是 `アパート`，不要混成 `デパート`。
- 用户给出的故事通常更贴近日常，要优先保留原味；自己生成时要主动模仿这种“生活经验 + 俏皮谐音 + 明确含义”的结构。

## 文件结构要求

批次来源优先级：

- 编写或审核记忆方法时，优先以 `data/memory_methods/batch_*_methods.json` 的词表为准。
- N4 词汇初版来自 `资源汇总/N4/MOJi辞書 - 红宝书N4N5 1~1000.pdf` 和 `资源汇总/N4/MOJi辞書 - 红宝书N4N5 1001~1220.pdf`，生成脚本是 `scripts/build_n4_memory_methods.cjs`，正式批次放在 `data/memory_methods/n4/`。
- 如果 `data/batches/batch_*.json` 和 `data/memory_methods/batch_*_methods.json` 不一致，先明确指出差异；除非用户指定，否则继续以 `data/memory_methods` 为准。
- 不要因为同编号 `data/batches` 里有重复旧批次，就把已经完成的词组重新生成一遍。

保持原有 JSON 字段，不随意改名：

- `word`
- `reading`
- `meaning`
- `elements`
- `mergedScene`
- `sceneScore`
- `reviewTip`
- `difficultyStars`
- `exampleSentences`

不删词，不换顺序。未确认前，新批次先放到 `data/memory_methods/drafts/` 作为草稿。

`exampleSentences` 统一使用数组格式：

```json
[
  {
    "ja": "日本語の例文です。",
    "zh": "中文翻译。"
  }
]
```

旧批次里如果已经存在 `exampleSentence`、`examples`、`sentences` 或 `exampleSentences`，先保留原字段；新批次统一使用 `exampleSentences`。

## 记忆方法风格

每个词优先使用三层结构：

1. 发音联想：优先找自然、好记的中文谐音。
2. 小故事绑定：把谐音变成有趣、具体、生活化的小故事，让故事自然导向单词意思。
3. 汉字/固定读音辅助：中文能直接看懂的，用汉字本义、固定读音或外来语补强。
4. 易混控制：和相近词、相近读音、相近语法做对比提醒。
5. 相似词成对记忆：当两个词只差几个假名、一个点或一个长音时，优先把它们放在一起，通过“差异点”绑定意思差异。
6. 多读音追踪：同一个汉字如果在前面批次出现过不同读法，必须标记并积累；尤其是 `書` 这类常见字，见到新读法要写进元素和规则，防止下次不会读。

优先级：

1. 用户提供的谐音和故事最高优先级，直接吸收。
2. 自己生成时，先找自然中文谐音，再把谐音变成一个具体小故事。
3. 如果有罗马音/英语/外来语相似，也可以作为强记忆点，比如 `namae≈name`、`neko→Nike`、`ニュース≈news`。
4. 汉字直觉和固定读音用于补强，不要压过好玩的谐音故事。
5. 谐音生成必须按顺序尝试：先多试几个整体谐音，选发音最贴近、最容易一眼想起的；如果整个单词的发音直接谐音不自然，优先把发音拆成 2 到 3 段分别谐音，再合成故事；如果拆开仍然不合理，就改用假名字形、汉字直觉、固定读音、外来语或生活联想，不要硬凑。比如 `つまらない` 拆成 `つまら=吃麻辣` + `ない=没有`，`てがみ` 拆成 `特 + 加 + 密`。
6. 如果两个单词非常相像，优先找“少了什么/多了什么/换了什么”的视觉差异来记；比如 `ちょっと` 比 `ちょうど` 少了一个点，所以是“一点”，`ちょうど` 正好多了一点，所以是“正好”。
7. 当两个单词假名十分接近时，可以使用“字型变化法”：观察假名多了点、少了点、弯了一下、转了一圈、清音变浊音等变化，把这个变化和意思差异绑定。
8. 当两个词只是假名增减且意思相近时，优先考虑语法差别：比如名词/状态词加 `る` 变动词，名词后面加动词结尾变成动作。
9. 当两个词同音或读音完全一样但意思不同，要集中成组串联含义，靠汉字、场景和用法区分，不要分散硬背。
10. 当两个词意思相反或成对出现，可以编一个谐音梗把两边一起钉住，比如左/右、早/快、花/鼻。
11. 当两个词意思基本相同但语气、礼貌程度或使用场景不同，也要放在一起记；重点写清“都是什么意思”和“差别在哪里”，比如 `みなさん/みんな` 都是大家，`みなさん` 更礼貌，`みんな` 更口语亲近。
12. 做关联记忆时，不能只写“这两个词有关”。必须继续拆：比较假名增减、浊点、长音、促音、礼貌词尾、字形负重、谁跑得快/慢、谁更正式/亲近，再把差异编成小故事。比如 `また/まだ`：`た` 卸了两点包袱跑得快，所以“又来了”；`だ` 背着两个点走不快，所以“还没到”。

常用方法标签：

- `TYPE A1`：汉字直觉
- `TYPE B2`：发音联想
- `TYPE B1`：假名/字形联想
- `外来语`
- `固定读音`
- `关联记忆`
- `语法记忆`
- `对比记忆`

## elements 写法

- 每个词 1 到 4 个记忆点即可。
- 不要把每个假名都机械拆开，只拆真正有记忆价值的部分。
- 汉字透明的词要短，难混的词要多写对比。
- 外来语优先说明英文或来源词。
- 固定组合要直接提醒整体读音，比如 `今年=ことし`。

## mergedScene 写法

- 用 1 到 3 句中文画面。
- 必须有具体人物、场景、动作、物品或情绪。
- 可以荒诞、搞笑、夸张，只要能帮助记住。
- 最好写成“一词一小戏”：谁在什么地方，因为谐音做了什么事，最后自然落到单词意思。
- 用户给的生活化故事要尽量保留原味，比如老婆回答、奴家脱衣服、戒烟砸烟灰缸、给鸭一张卡。
- 不要写空泛句，比如“这个词很好记”。

## reviewTip 写法

- 第一行优先判断是否有自然、好记、不生硬的谐音。
- 有自然谐音时，必须使用格式：`发音 - 谐音 - 联想过程 - 单词意思`。
- 有罗马音/英语相似时，使用格式：`发音 - 罗马音/英语相似点 - 联想过程 - 单词意思`。
- 没有自然谐音时，不强行写“无谐音”，改用汉字直觉、固定读音、外来语、语法、对比记忆或生活场景。
- 透明汉字词、外来语、固定组合优先直接解释，不硬凑中文谐音。
- 用 `⚠️` 标常见坑。
- 用 `🔗` 串联相关词。
- `reviewTip` 里可以放短例句，但结构化例句必须放进 `exampleSentences`。

## exampleSentences 写法

- 每个词至少 1 条例句。
- 例句优先贴合当前学习阶段；没有特别说明时，先用简单自然的基础句，不写复杂从句。
- 例句要自然、短、能直接体现单词用法。
- `ja` 写日语，`zh` 写中文翻译。
- 动词优先给真实搭配，比如 `歯を磨きます`、`バスに乗ります`。
- 名词和形容词避免机械套 `これは...です`，能给场景就给场景。

示例格式：

`こたえる - 谐音“可太爱了” - 老婆问爱不爱她，你回答“可太爱了” - 回答`

`はいざら - 谐音“害了，砸了” - 戒烟的人看见烟灰缸心痒，干脆把它砸了 - 烟灰缸`

`なまえ - 罗马音namae像英语name - 表格上的name栏就是写名字 - 名字`

`今月：今固定读こん，月固定读げつ；现在这个月就是今月=这个月`

`シャワー：外来语 shower，水从喷头冲下来=淋浴`

`⚠️ 今年特殊读ことし，不读こんねん。`

`🔗 今月、今週、今晩是一组。`

`つまらない - 拆成“つまら=吃麻辣 + ない=没有” - 四川人饭里没有吃麻辣，就会觉得很无聊 - 无聊的`

`てがみ - 拆成“特 + 加 + 密” - 一封特别加密的信 - 信`

`でる - 谐音“得喽/得噜” - 不上班被父母天天念叨，最后大喊“得喽”才出门 - 出去`

`でんわ - 谐音“等哇” - 为了特殊任命通知，在电话前等哇等哇 - 电话`

`どうぶつ - 谐音“都不吃” - 因为都是保护动物，所以都不吃 - 动物`

`とおか - 谐音“读卡” - 公司每月十号发工资，员工都在十号读卡查工资 - 十号`

`ときどき/どきどき：ときどき=有时；どきどき=心动/心跳。可以联想“有时对她很心动”，どきどき前面的两点像心脏跳动。`

`とけい - 谐音“躲开” - 在时间面前任何人都不可能躲开，时钟显示时间 - 钟表`

`ところ - 谐音“偷可乐” - 小孩总去固定地方偷可乐 - 场所/地方`

`となり - 谐音“偷哪里” - 两个小偷商量偷哪里，另一个回答邻居家 - 旁边/隔壁`

`ともだち - 谐音“偷摸拿鸡” - 好朋友就是一起偷摸干搞怪事的哥们 - 朋友`

`どようび - 周一到周五胡吃海喝，周六没钱只能吃土 - 周六`

`撮る(とる) - 谐音“偷录” - 偷偷录制或者拍摄视频 - 照相/拍摄`

`せびろ - 谐音“帅毙了” - 男人一穿上西服就显得帅很多 - 西服`

`せんたく - 谐音“掀他裤” - 孩子裤子太脏又不想换，只好掀开洗洗 - 洗衣服`

`そうじ - 谐音“扫圾” - 扩展成打扫垃圾，所以是打扫 - 打扫`

`だいがく - 谐音“太开阔” - 第一眼来到大学校园，发现真的很开阔 - 大学`

`たいしかん - 谐音“他一细看” - 他一细看发现竟然是大使馆 - 大使馆`

`だいどころ - 谐音“打一桶可乐” - 结合ところ“偷可乐”，小孩经常去厨房偷可乐 - 厨房`

`だす - 谐音“打死” - 用极端抢劫故事记“逼到最后才拿出财宝” - 拿出/取出`

`たつ/たて：たて就是たつ站起来后的样子；站起来就变成竖起来的东西。`

`はいる - 谐音“嗨一路” - 进入大堂前跟很多人打招呼说hi，说了一路才进去 - 进入`

`葉書：葉=树叶，書=书信；古代文人互送明信片，会把当地树叶夹在书信里。注意書在図書館读しょ，在葉書读がき。`

`はじめ组：始まる/初め/始め/初めて一起记。始读haji，可用“哈尔滨吉林都开始修马路了”记开始；初め偏最初，始め偏开始动作，初めて是初次。`

`はなし/はなす：はなし是名词“话”，はなす是动词“说话”；す结尾常见于动词。`

`はやい：早い/速い同读。因为跑得快所以到得早；也可谐音“好压抑”，每天很早上班还跑得很快。`

`はる组：春/貼る一起记。开春过春节，大家哈大笑，还要把春联贴上去。`

`晴れ/晴れる：晴れ是晴天状态，晴れる是后面加る动词化，表示放晴。`

`半/晩：半读はん；晩读ばん。ばん比はん多两点，像太阳被两朵云遮住进入傍晚。`

`東(ひがし)和光(ひかり)：光从东方来，か变が，り顺时针转成し，像往东边转。`

`飛行機(ひこうき)：機基本读ki；ひこうき可谐音“he阔气”，他很阔气，买了一架飞机。`

`左/右：左ひだり可谐音“意大利”，右みぎ可联想“美国”，用相反词成对区分。`

`本棚(ほんだな)：本固定发ほん；ほんだな可谐音“红的呐”，一个人的书架居然是红的呐 - 书架。`

`ほんとう：可以用网上常见“红豆泥”谐音梗记；“红豆泥？”就是“真的吗？”；前面的ほんとう就是“真的”。`

`また/まだ：また反过来像“他嘛”，老师提问时大家希望老师再喊那个学霸，心里默念“他嘛他嘛”，结果又是学霸回答。まだ和また要做假名字形拆分：た卸了两点包袱跑得快，所以また=又来了；だ背着两个点走不快，所以まだ=还没到。`

`万年筆(まんねんひつ)：年固定读ねん，筆固定读ひつ；能写很多年的笔 - 钢笔。`

`磨く(みがく)：みがく谐音“蜜瓜苦”；蜜瓜表面的皮是苦的，所以需要反复打磨 - 刷、磨。`

`短い(みじかい)：みじかい谐音“秘籍开”；打游戏一开秘籍，就会短时间内提升战斗力 - 短的。`

`道(みち)：みち谐音“米奇”；想象一个米奇走在大路上 - 道路。`

`皆さん/みんな：みなさん和みんな都是“大家”；みなさん=みな+さん，带さん更礼貌，适合课堂、公开场合；みんな少了さん，两个ん挤成一团，更口语亲近，适合朋友之间。`

`ひとり/ふたり：ひとり=一个人吃梨，没有人跟你抢；ふたり=两个人吃梨，为了吃到就要互相打架。用同一个“梨”场景区分一个人/两个人。`

`病院/病気：病经常固定读びょう；病院=びょういん，病気=びょうき。病院是地方，病気是状态。`

`吹く(ふく)：ふ像风吹过的“呼呼”声，呼呼地把风吹出来 - 吹。`

`豚肉(ぶたにく)：ぶた可看成ふた“两层”加两点猪毛，にく=肉；菜市场猪肉分外层肥肉、内层瘦肉 - 猪肉。`

`太い(ふとい)：拆成ふ=腹，と=凸起来的啤酒肚；腹部有啤酒肚，看起来很粗/胖 - 粗的。`

`冬(ふゆ)：ふ像风刮过来的“呼呼呼”声；北方冬天风最多也最冷 - 冬天。`

`降る/古い：ふる是降下来；ふるい多一个い，可谐音“已”。雨雪从天上落下来后已经被灰尘污染，变得不新了，所以ふるい=旧的。`

`ふろ：谐音“浮咯”；泡澡时有各种泡泡在浴池里浮起来 - 浴池。`

`下手(へた)：へた谐音“害他”；手下做事太笨，很容易害他 - 笨拙、不擅长。`

`辺(へん)：へん优先谐音“恨”，不要误用发音偏差的“边”。一个人总是恨周围附近的人，觉得他们过得都比自己好 - 附近。`

`勉強する(べんきょうする)：べんきょう谐音“笨Q”；笨Q知道自己笨，但相信勤能补拙，所以非常勤奋 - 学习。`

`便利(べんり)：便在便利读べん，在郵便局读びん；同一个汉字出现不同读法，要放进多读音记录。`

`来月/来週/来年：来固定读らい，表示未来来的下一个时间单位；月=げつ，週=しゅう，年=ねん。`

`ラジカセ/ラジオカセット：ラジカセ是ラジオカセット的缩略；ラジオ=radio，カセット=cassette。相同物品的长短说法要一起记。`

`若い/分かる：两个都以わか开头。若い可谐音“娃可爱”，年轻的小娃很可爱；分かる可谐音“挖开了”，把问题挖开看清楚就明白。`

`渡す/渡る：同一个渡字，渡す=把东西渡过去给别人，す像手伸出去；渡る=自己渡过桥或路，る像人自己绕过去。`

`私(わたくし)：比わたし更正式，中间多く，像正式场合多扣一颗礼貌扣子。`

`ほう：方表示方向时读ほう；前面夕方中方读がた。同一汉字不同读法要记录，方=ほう/がた。`

`むずかしい - 拆成“む=母，ず=子，かしい=看戏” - 母子生活艰难，旁人只看戏，世态炎凉 - 难的`

`めがね - 谐音“没看呢” - 没带眼镜所以没看到呢 - 眼镜`

`木曜日：木有四笔画，所以联想到星期四；木=もく，曜=よう，日=び。`

`もっと/持つ：持つ(もつ)=持有；もっと比もつ多一个と，像多抱了一个写着と的包，所以是更多、更加。`

`やおや - 谐音“呀-藕-呀” - 蔬菜店全卖藕，像莲藕专卖店 - 蔬菜店`

`やさしい - 谐音“压撒西” - 日漫中常见这个读音；写作易しい时表示容易的 - 容易的`

`やすい - 谐音“呀！11！” - 走进苹果店发现竟然才卖11，惊讶觉得太便宜 - 便宜的`

`やすむ/やすみ：やすむ谐音“要死噜”，累得要死了所以要休息；やすみ是名词化，表示休息/假期。`

`夕方/夕飯：夕=ゆう，可谐音“悠”；方=がた，也有这位/人的意思；夕阳下悠闲吃饭看风景，就是傍晚和晚饭场景。`

`ゆっくりと - 谐音”又苦哩” - 因为又要受苦了，所以做得慢慢地 - 慢慢地`

`洋服：服=ふく，这是高频读音；洋=西洋，洋服就是西洋衣服。`

`すべる - 谐音”四白楼” - 想象从四百楼滑下来，摔死了 - 滑行滑动`

`きせつ - 谐音”ki四次” - ki发音像刀切东西的声音，想象一年被切成了四次，所以是四季 - 季节`

`ちがい - 🔗 和ちかい对比：ちがい比ちかい多了两个点（浊点），所以有所差异 - 差，差异`

`おいでになる - おいで谐音”哦你爹”，になる谐音”来噜”；在日本说你爹来噜的时候需要用敬语 - 去，来（敬语）`

`せいこう - 谐音”谁扣” + せい=成，こう=功（固定读音）；成功的关键在于”谁扣”得紧，谁坚持到最后 - 成功`

`もれる - 谐音”莫了噜” - 因为漏水漏了太多，所以一点都没了 - 漏，漏出`

`すみ - 谐音”私密” - 角落是私密的藏身处，所以记住这个音 - 角落`

`おかげ - 🔗 和おかけで语法关联：おかけで表示多亏了xxx；多亏本质是得到了xxx的庇护或帮助 - 保佑，庇护`

`せなか - せ谐音”赛”（比赛谁的背大），なか固定读音；背=せ，中=なか/ちゅう两个读音 - 背，脊背`

`とっきゅう - 谐音”头q” - 一个小孩吃了qq糖之后，头就特快的转 - 特快，特别快车`

## 常见固定读音记录

遇到常见汉字读音，要在方法里顺手标注，方便后续批次复用：

- `今`：在 `今月/今週/今晩` 中常读 `こん`。
- `月`：在 `今月` 等月份相关词里常读 `げつ`。
- `週`：常读 `しゅう`。
- `時`：在 `時間` 中读 `じ`。
- `間`：在 `時間` 中读 `かん`。
- `生`：大多数常见复合词里可读 `せい`，如 `先生/生徒`；遇到生相关词先考虑这个读音。
- `天`：基本读 `てん`，如 `天気`。
- `気`：基本读 `き`，如 `天気/電気`。
- `電`：基本读 `でん`，如 `電気/電車/電話`。
- `話`：在 `電話` 中读 `わ`，表示说话、话语。
- `飯`：常读 `はん`，如 `御飯/朝ご飯/昼ご飯/晩ご飯`。
- `年`：常读 `ねん`，但 `今年` 日常读 `ことし`。
- `曜`：星期词里常读 `よう`。
- `日`：在 `日曜日` 开头读 `にち`，在 `曜日` 末尾常读 `び`。
- `水`：在 `水曜日` 中读 `すい`。
- `木`：在 `木曜日` 中读 `もく`；木有四笔画，可联想星期四。
- `車`：单独作“车”常读 `くるま`；复合词里常读 `しゃ`，如 `自転車/自動車/電車`。
- `自`：常读 `じ`，如 `自分/自転車/自動車`。
- `動`：常读 `どう`，如 `自動車`。
- `写`：在 `写真` 中读 `しゃ`。
- `真`：在 `写真` 中读 `しん`。
- `授`：在 `授業` 中读 `じゅ`。
- `業`：在 `授業` 中读 `ぎょう`。
- `宿`：在 `宿題` 中读 `しゅく`。
- `題`：在 `宿題` 中读 `だい`。
- `食`：在 `食堂` 中读 `しょく`。
- `堂`：在 `食堂` 中读 `どう`。
- `切`：经常读 `せつ`，如 `大切`，以后遇到相关词优先留意。
- `物`：常读 `ぶつ`，如 `動物`。
- `書`：常读 `しょ`，如 `図書館`；在 `葉書(はがき)` 中读 `がき`，遇到同一汉字新读法要主动记录。
- `館`：常读 `かん`，如 `図書館`。
- `始`：在 `始まる/始め` 中读 `はじ`，可用 haji 组记开始。
- `番`：固定读 `ばん`，如 `番号/順番`。
- `機`：基本读 `き/ki`，如 `飛行機`。
- `夕`：常读 `ゆう`，如 `夕方/夕飯`。
- `方`：在 `夕方` 中读 `がた`。
- `服`：高频读音 `ふく`，如 `洋服/服`。
- `土`：在 `土曜日` 中读 `ど`。
- `肉`：常读 `にく`，如 `とり肉`。
- `茶`：常读 `ちゃ`，如 `茶色/ちゃわん`。
- `色`：常读 `いろ`，如 `茶色`。
- `口`：单独常读 `くち`；放在复合词后面可能浊化成 `ぐち`，如 `入口(いりぐち)`、`出口(でぐち)`。
- `本`：作“书”时常读 `ほん`，如 `本/本棚`；遇到含本的词先考虑这个音。
- `棚`：在 `本棚(ほんだな)` 中读 `だな`，表示架子。
- `筆`：在 `万年筆(まんねんひつ)` 中读 `ひつ`，表示笔。
- `病`：经常读 `びょう`，如 `病院(びょういん)`、`病気(びょうき)`。
- `便`：多读音；在 `便利(べんり)` 中读 `べん`，在 `郵便局(ゆうびんきょく)` 中读 `びん`。遇到同一汉字不同读法要主动标记。
- `来`：在未来时间词里常读 `らい`，如 `来月(らいげつ)`、`来週(らいしゅう)`、`来年(らいねん)`。
- `冷`：在 `冷蔵庫(れいぞうこ)` 中读 `れい`。
- `蔵`：在 `冷蔵庫(れいぞうこ)` 中读 `ぞう`，表示储藏。
- `庫`：在 `冷蔵庫(れいぞうこ)` 中读 `こ`，表示库、仓库。
- `方`：多读音；表示方向时读 `ほう`，如 `右のほう`；在 `夕方(ゆうがた)` 中读 `がた`。
- `下`：多读音；在 `廊下(ろうか)` 中读 `か`，此前也有 `下手(へた)`、`下(した)` 等读法。
- `犯`：固定读 `はん`，如 `犯人(はんにん)`。
- `人`：在复合词中常读 `にん`，如 `犯人(はんにん)`。
- `中`：有两个读音 `なか` 和 `ちゅう`；`なか` 表示"里面"，`ちゅう` 表示"中间/中国"，如 `背中(せなか)`、`昼食(ちゅうしょく)`、`中国(ちゅうごく)`。
- `社`：大部分发 `しゃ` 的音，如 `社会(しゃかい)`。
- `会`：大部分发 `かい` 的音，如 `社会(しゃかい)`。
- `始`：在日语中大多数都发 `はじ` 的音，如 `始める(はじめる)`、`始まる(はじまる)`。
- `背`：在 `背中(せなか)` 中读 `せ`，可谐音"赛"记忆。

用户提供新的固定读音、谐音或场景时，优先吸收进当前草稿和本规则。

## 难度规则

- `difficultyStars: 1`：汉字透明、外来语明显、读音稳定。
- `difficultyStars: 2`：纯假名、需要谐音、容易和相近词混。
- `difficultyStars: 3`：多义、多读音、用法抽象、特别容易混。

## sceneScore 规则

- `specific`：画面是否具体。
- `emotional`：是否有幽默、惊讶、紧张、尴尬、痛感、温暖等情绪。
- `personal`：是否能贴近日常、学习、考试、动漫、家庭、食物、钱、学校、旅行等经验。
- `total`：上面三个 true 的数量。

## 用户偏好

- 单词记忆方法优先考虑谐音，再通过谐音变成有趣的小故事。
- 中文谐音可以大胆一点，只要好记。
- 谐音必须自然，不要为了满足格式硬凑。
- 可以使用离谱、生活化、轻微吐槽式画面。
- 可以用中文、英文、罗马音混合联想；只要一眼能记住，就优先保留。
- 故事越具体越好：人物、动作、物品和结果要清楚。
- 多做家族串联：`今月/今週/今晩/今年`、`こちら/こっち/これ/この/こんな`、`三/四/七`。
- 易混词必须提醒：比如 `こっち/こちら`、`さき/さく`、`しち/なな`、`砂糖/塩`。
- 最终目的是复习时一眼能想起来，不追求文学感。
- 如果参考外部评论或词典，只能吸收思路，不能照抄长句。
