# 批量记忆法批改规则

在逐批协作模式中，用户批改时使用以下前缀规则：

每次处理完用户批改后，都要同步复盘本轮修改里出现的新记忆规律，并更新 `data/skill/日语所有单词记忆方法规则.md`。这个规则文件是后续所有批次生成的核心依据。

| 前缀 | 含义 | 操作 |
|------|------|------|
| `e数字` | 替换 | 删除该单词的原记忆方法，替换为用户提供的新记忆方法 |
| `p` | 新增 | 给该组新增遗漏的单词（追加到末尾，重新编号） |
| `数字`（无前缀） | 补充 | 仅给该单词增加/修改记忆方法（不删除原有内容） |
| `d数字` | 删除 | 该单词识别错误，从列表中删除整条记录 |
| `c数字` | 部分更改 | 仅修改该单词记忆方法的某个部分，不全部替换（需同时说明删什么/改什么） |

## 示例

```
e15  → 替换第15个单词的记忆方法
p    → 新增一个单词到末尾
11   → 给第11个单词补充记忆方法
d3   → 删除第3个单词（识别错误）
c17  → 部分修改第17个单词的某个部分（需说明具体删改）
```
