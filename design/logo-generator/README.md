# Kotoba 日语学习 App Logo 方案

本目录由 `logo-generator` skill 生成，用于挑选日语学习 App 的图标方向。

## 文件

- `showcase.html`：7 个 Logo 方案总览页，可直接浏览。
- `svg/*.svg`：每个方案的可编辑矢量源文件，统一使用 `viewBox="0 0 100 100"`。

## 初始设计假设

- 产品：日语学习 App / Kotoba。
- 核心卖点：单词记忆方法、词卡、记忆链路、故事化学习。
- 视觉方向：低饱和自然绿色、纸本白、少量暖棕；简洁、适合 iOS App 图标。

## 推荐优先看

1. `07-final-recommended.svg`：精修后的 iOS 图标候选，白底、词卡轮廓、右上叶片和中心「あ」更清晰。
2. `01-leaf-card-a.svg`：最贴近你之前喜欢的“单词卡片 + 叶片 + あ”方向，可作为备选。
3. `02-memory-chain.svg`：更强调“记忆链路”，适合平台主视觉。
4. `05-soft-jp-card.svg`：如果想保留 JP 字样，可以继续从这个方向细化。
